**Important:** The presence of font files in the repository does not establish their origin or licensing status. Confirm the original source and retain the corresponding official licence documents before production deployment or redistribution.

## 4. Permitted Use and Compliance

Before using either font family, verify that the applicable licence permits the intended activities.

### Website use

Confirm permission to:

- Embed the fonts in website stylesheets.
- Serve the font files from the MedOrbits domain.
- Use the fonts in public-facing educational and healthcare pages.
- Use the fonts in forms, dashboards, and other website interfaces.
- Use the fonts for commercial purposes if applicable to the project.

### Repository distribution

Before committing or publishing font binaries, confirm whether the licence permits:

- Storing the files in a private repository.
- Including the files in a public repository.
- Redistributing the files with website source code.
- Bundling the files in deployment packages.
- Converting TTF files to WOFF or WOFF2.
- Subsetting or modifying the original font files.

Permissions can differ by licence and distribution method. Do not assume that permission to use a font on a website automatically permits unrestricted redistribution of its binary files.

Obtain font files and licence information from the original font publisher, an authorized repository, or another trustworthy source.

For each family, retain the original licence text and relevant copyright notices in the repository where required.

The two `.txt` files are recommended filenames for the original licence documents. Add them only after obtaining and verifying the actual documents.

Do not create placeholder licence text that could be mistaken for an official licence.

## 6. Attribution Requirements

Follow the exact attribution requirements specified by each applicable licence.

Where attribution is required, record:

- Font family and creator.
- Copyright notice.
- Licence name.
- Required attribution wording.
- Source or official project page.
- Any restrictions or additional notices.

Do not invent attribution statements or remove copyright information supplied with the original font files.

If a licence does not require attribution, do not falsely claim that it does. Retain the licence documentation as appropriate.

—

## 7. Font Conversion and Optimization

MedOrbits may consider converting existing TTF files to WOFF2 to reduce website transfer size.

Before conversion:

1. Review the original font licence.
2. Confirm whether modification and format conversion are permitted.
3. Preserve the original files until the converted versions have been tested.
4. Keep applicable copyright and licence notices.
5. Verify the converted font’s family, weights, styles, and glyph coverage.
6. Test the converted files in supported browsers.
7. Update CSS references only after the converted files are available and verified.

Do not replace existing production font files with untested conversions.

## 8. Compliance Responsibilities

The project maintainer is responsible for ensuring that font assets are appropriately sourced and used.

The review should confirm that:

- Each font has an identifiable source.
- The applicable licence has been reviewed.
- Commercial and website use are permitted where required.
- Repository distribution complies with the licence.
- Required copyright and attribution notices are retained.

- Licence documents are included when required.

This document is an internal tracking record. It does not replace the original font licences or constitute legal advice.
