1. Purpose

The assets/images/career/ directory contains visual assets supporting MedOrbits career guidance, internship assistance, job-search resources, professional development, and recruitment-related services.

These assets may be used across:

* Career guidance and planning pages
* Internship information and support
* Job-search resources
* Professional development services
* Recruitment and employment support
* Career counselling and skills development
* Career-related articles and landing pages
* Promotional and informational content

Career imagery should communicate the intended service accurately and maintain a consistent, accessible, and professional website experience.

3. Brand and Visual Direction

All career images must complement the established MedOrbits visual identity.

Brand palette

Use existing colour tokens, gradients, typography, and component styles.

Career imagery should be:

* Professional and visually refined
* Relevant to career planning or employment services
* Consistent with the premium MedOrbits presentation
* Suitable for desktop and mobile layouts

If an asset is an abstract branded illustration, do not present it as a documentary photograph of a real employee, employer, workplace, or recruitment event.

5. Naming Conventions

* Use lowercase filenames.
* Separate words with hyphens.
* Prefer JPG for optimized raster illustrations and content imagery.
* Use SVG for suitable scalable vector artwork.
* Keep filenames stable after production references are established.
* Avoid unclear suffixes such as final, new, latest, or final-2.
* Check for existing assets before creating duplicates.
* Update this README when the approved inventory changes.

Before renaming or removing files, inspect references in HTML, CSS, JavaScript, JSON, and other application configuration.

  decoding=“async”

This example assumes the image exists and its dimensions match the specified values. Verify both before using the markup.

Use alt=“” for decorative imagery when the surrounding content communicates the relevant information. Provide concise alternative text for informative images.

Adapt the asset path if the application is deployed under a subdirectory rather than the domain root.

8. Optimization and Loading

Recommended practices:

* Compress images before publishing.
* Resize images to appropriate display dimensions.
* Prefer JPG for supported raster imagery.
* Remove unnecessary metadata.
* Use responsive image sources where beneficial.
* Specify image dimensions or reserve layout space.
* Lazy-load below-the-fold images where appropriate.
* Avoid unnecessary JavaScript-based image loading.

Do not lazy-load the primary above-the-fold image by default when it is the likely Largest Contentful Paint element.

File size alone does not establish visual quality, correct dimensions, or production suitability.

9. Accessibility and Content Accuracy

* Use meaningful alternative text for informative images.
* Use empty alternative text for decorative images.
* Maintain sufficient text contrast.
* Keep headings, descriptions, and calls to action as HTML.
* Preserve keyboard navigation and visible focus indicators.
* Avoid relying on colour alone to communicate meaning.
* Ensure essential career information remains available as text.
* Do not use imagery to imply guaranteed employment or professional outcomes.

Descriptions of recruitment, internship, and job-search services must match the services MedOrbits actually provides.

10. Missing Assets and Fallbacks

When a career image is unavailable:

* Use a verified existing fallback from the project’s placeholder library, if appropriate.
* Preserve the image container dimensions.
* Keep the service title, description, and actions visible.
* Avoid broken-image indicators where practical.
* Verify the fallback path before using it.
* Do not replace an entire service card when only its image is missing.
* Preserve the established website design system.

A missing image should not prevent users from accessing the associated career information.

11. Copyright and Licensing

Before publishing or replacing an image:

* Verify ownership or permission to use the asset.
* Confirm commercial-use and modification rights.
* Provide attribution when required.
* Obtain appropriate releases for identifiable individuals where necessary.
* Avoid unauthorized third-party logos.
* Do not fabricate employee profiles, employer partnerships, testimonials, or job placements.
* Maintain source and licensing records where appropriate.
