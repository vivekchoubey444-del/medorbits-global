1. Purpose

The assets/images/study-abroad/ directory contains visual assets supporting MedOrbits’ international education and overseas study guidance services.

These images provide visual context for students exploring international universities, educational opportunities, visa guidance, and pre-departure preparation.

Images may be used for:

* Study abroad landing pages
* International education service cards
* University discovery and course exploration
* Student visa guidance
* Pre-departure preparation
* International admissions information
* Overseas education counselling
* Study abroad promotional campaigns
* Related educational content and resources

All imagery should accurately represent the associated content and maintain a consistent visual identity across the website.

8. Optimization and Loading

Study abroad images should balance visual quality and page performance.

Recommended practices:

* Compress images before publishing.
* Resize images to appropriate display dimensions.
* Prefer JPG for supported raster imagery.
* Remove unnecessary metadata.
* Use responsive image sources where beneficial.
* Specify image dimensions or reserve layout space.
* Lazy-load below-the-fold images where appropriate.
* Avoid unnecessary JavaScript-based image loading.
* Avoid serving oversized originals when smaller files provide sufficient quality.

Do not lazy-load the primary above-the-fold image by default when it is the likely Largest Contentful Paint element.

Assess the actual visual quality and performance of each asset rather than relying on file size alone.

9. Accessibility and Content Accuracy

* Use meaningful alternative text for informative images.
* Use empty alternative text for decorative imagery.
* Maintain sufficient text contrast.
* Keep headings, descriptions, and calls to action as HTML.
* Preserve keyboard navigation and visible focus indicators.
* Avoid relying on image colour alone to communicate meaning.
* Ensure essential study guidance remains available as accessible text.
* Do not use imagery to imply unsupported educational outcomes.

Visa requirements, university admission criteria, qualification recognition, tuition costs, and immigration rules may vary by destination and change over time. Keep these details in appropriate content sources rather than embedding essential information directly into images.

10. Missing Assets and Fallbacks

When a study abroad image is unavailable:

1. Use a verified existing placeholder when appropriate.
2. Preserve the original image container dimensions.
3. Keep the relevant headings, descriptions, and controls visible.
4. Avoid broken-image indicators where practical.
5. Verify that the fallback path resolves correctly.
6. Avoid replacing the entire component when only its image is missing.
7. Preserve the existing website design system.

Do not reference a proposed image or mobile variant in production until the file exists.
