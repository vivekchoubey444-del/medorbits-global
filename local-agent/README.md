# MedOrbits Local Agent\n\nPython 3.10+ standard-library file generator and validator. See commands and safety notes in this README.\n\nCommands: `status`, `inventory`, `validate`, `plan --spec FILE`, `create --spec FILE [--dry-run] [--force]`, `scaffold --spec FILE [--apply] [--force]`. `plan` is dry-run. Existing files are skipped unless `--force`; replacements are backed up. No installs, downloads, code execution, SQL execution, deployment, or Git mutation.\n
