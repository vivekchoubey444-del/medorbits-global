Status guide

Understand common ticket statuses.

The descriptions below explain common support terminology. They are guidance only and are not live statuses for any individual MedOrbits ticket.

Received

Request received

A request has been recorded by the relevant system. Look for an acknowledgement or reference number confirming that it was actually received.

In review

Under review

The request may be awaiting assessment. If information is missing, the responsible team may need additional details.

Awaiting information

More information needed

The support team may need clarification or supporting information. Provide only what is relevant and requested.

In progress

Work in progress

The request may be undergoing further checks or action. Follow any instructions provided by the responsible team.

Resolved

Marked as resolved

A resolution may have been recorded. Review the response and ask the appropriate contact for clarification if needed.

Closed

Ticket closed

The request may have been closed according to the applicable process. Ask whether reopening or submitting a new request is appropriate if the issue remains.

!

Ticket status is not currently retrieved by this page

A working ticket tracker needs a server-side endpoint connected to the ticket database. That endpoint should validate the reference, verify the requester's authority to access the ticket, enforce rate limits and return only the minimum information required. Never expose ticket records by accepting a reference number alone without appropriate access controls.

Frequently asked questions

Ticket tracking questions.

Answers to common questions about references, follow-ups and ticket information.

How do I find my ticket number?
Check the acknowledgement or confirmation you received after submitting your request. If no reference was issued, contact the relevant support channel and explain when and how you submitted the request.
Why can this page not show my live status?
The current page is a frontend template and is not connected to a ticket database or status API. A backend integration is required before live status retrieval can work.
What if my reference number is not recognised?
Check the reference for typing errors and confirm that you are using the correct support system. If the issue continues, contact the original channel. Do not repeatedly submit sensitive personal details to troubleshoot a reference.
Does entering my ticket number create a new ticket?
No. This lookup form does not create a ticket or send a request. To raise a new issue, visit Submit a support ticket and follow the instructions on that page.
Can I check a ticket using another person's email?
Only access or request information you are authorised to receive. Ticket records may contain private information. The production tracker should verify access before returning any ticket details.
What should I do if a ticket is marked resolved but my issue remains?
Refer to the resolution message and contact the responsible support channel with the existing reference number. Explain what remains unresolved and ask whether a review or reopening process is available.
How long does a ticket take to resolve?
Resolution time depends on the issue and the applicable service process. This page does not guarantee a response or completion deadline. Refer to any published service terms or acknowledgement that applies to your request.
