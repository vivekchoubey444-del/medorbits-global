Support FAQs

Before you contact support.

Quick answers to common questions about using the support centre.

How do I choose the correct support page?
Select the topic that best matches your issue. Use document upload help for file problems, payment support for transaction questions, refund requests for refund-related enquiries, and complaints for service concerns. If you are unsure, visit the contact page.
How do I check an existing support ticket?
Visit the ticket status page and follow the instructions provided there. You may need the reference number issued when the ticket was submitted. A status can only be retrieved if the underlying ticket system supports that function.
Does opening a support page automatically create a ticket?
No. Opening a page does not by itself submit a request. Check the individual page for its submission instructions and confirmation. Do not assume that a ticket has been created unless the system confirms it.
What should I include when reporting a technical issue?
Describe what you were trying to do, what happened instead, and approximately when the issue occurred. Include the page name and a relevant error message if available. Do not include passwords, OTPs, payment credentials or unnecessary personal information in screenshots.
Can I send documents by email?
Only send documents by email when the recipient and process have been verified and email is an appropriate channel. Ask for a secure submission method if the documents contain sensitive information. Follow the relevant official portal's file-format and size instructions.
How quickly will support respond?
This landing page does not promise a response time or resolution deadline. Check the terms or service-specific guidance for any applicable timeframe. Keep any acknowledgement or reference number you receive.
Where can I read MedOrbits policies?
Visit the Privacy Policy, Terms and Conditions, Refund Policy and Disclaimer for the relevant published information.
