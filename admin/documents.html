File security notice: This page is an administrative interface, not an access-control boundary. The backend must authenticate requests, enforce role-based permissions, validate document IDs, scan uploaded files, restrict permitted formats and audit sensitive operations. Never render untrusted HTML, execute uploaded scripts, or accept arbitrary file URLs from an API response. Private documents must not be exposed through public storage URLs. Confirm applicable copyright, privacy, retention and official-source requirements before publishing.
