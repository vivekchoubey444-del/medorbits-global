Receipt verification checklist

Review the underlying transaction before relying on a receipt.

01
Match the transaction

Compare the receipt identifier with the original payment record and trusted provider reference.

02
Validate amount and currency

Confirm the amount, currency, customer association and transaction state against the server record.

03
Check payment status

Use trusted provider confirmation and reconciliation data. Do not treat a pending transaction as paid.

≡

Receipt record lifecycle

Keep receipt issuance and payment settlement as distinct events.

01
Transaction initiated

A payment attempt is created and linked to a customer or application where applicable.

02
Payment confirmed

The backend validates the payment using trusted provider data before recording a successful state.

03
Receipt issued and retained

A server-controlled receipt record is linked to the transaction and preserved for audit and reconciliation.

Financial accountability

Reliable records. Traceable payments.

Preserve receipt identifiers, transaction references, issue timestamps and payment-state changes. Restrict access to authorised administrators and use server-generated receipt documents where downloadable copies are required.
