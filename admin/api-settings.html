Configuration checklist

Use these controls when reviewing API settings.

01
Keep secrets server-side

Store API keys, database URLs and private credentials in the deployment secret manager or protected environment variables.

02
Validate endpoints

Allowlist trusted destinations, require HTTPS in production and prevent server-side request forgery through user-controlled URLs.

03
Audit configuration changes

Record the authenticated actor, changed fields, reason, timestamp and outcome without logging credentials or tokens.
