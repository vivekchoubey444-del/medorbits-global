Export security

Protect data throughout the export lifecycle.

01
Enforce server permissions

Authenticate every request and check role-based access for each dataset and export action.

02
Minimise exported data

Export only the records and fields required for the approved purpose. Exclude unnecessary personal information.

03
Protect generated files

Use short-lived authorised download URLs, appropriate storage permissions, expiry and retention controls.

04
Record audit events

Log the requester, approved purpose, dataset scope, job result and relevant timestamps without exposing secrets.

▧

Format guidance

Choose the format that fits your workflow.

C
CSV for tabular analysis

Use for spreadsheets and simple tabular datasets. Escape cells correctly and protect against spreadsheet formula injection.

J
JSON for structured data

Use when nested objects, arrays and machine-readable records need to be preserved.

X
XLSX for workbook workflows

Use only when the server supports workbook generation and validates worksheet and cell content.

Governance · Traceability · Trust

Every export needs a purpose. Every file needs protection.

Keep administrative exports limited, auditable and temporary. Apply approved retention periods, restrict access to generated files, and follow the applicable data protection and security policies when handling student, applicant and user information.
