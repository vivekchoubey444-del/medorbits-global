Audit and security controls

Use audit logs and the security centre for administrative oversight.

Protect candidate and employer information.

Job records may include confidential employer details and recruitment information. The server must enforce authentication, role-based permissions and record-level access. Never expose private candidate information or employer contact details unless they are explicitly needed and authorised.

Security notice: This page is an interface, not an authorization boundary. Authenticate and authorise every API request on the server. Validate record identifiers, enforce record-level permissions, limit returned personal information and audit access to sensitive recruitment records.
