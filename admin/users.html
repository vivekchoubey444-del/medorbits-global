Protect user identity.

User accounts may contain names, contact details, education records and other personal information. Restrict administrative access, avoid exposing password hashes or authentication tokens, and record sensitive account changes in a protected audit trail.

Security notice: This page is a user interface, not an authorization boundary. Enforce authentication, role-based access control, server-side validation, rate limits, CSRF protection where applicable and audit logging in the backend. Never return password hashes, authentication secrets or unrestricted user records to the browser. Account suspension, role changes and deletion must be separately authorised server-side operations.
