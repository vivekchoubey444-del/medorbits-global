Responsible identity operations

Protect personal data. Preserve trust.

Use minimum-necessary data access, role-based permissions, secure session handling and auditable workflows when reviewing user profiles. Account changes must be performed through separately authorised backend operations.

Review security ↗ Audit history
Security notice: This page is a user interface, not an authorization boundary. The backend must authenticate the administrator, enforce record-level authorization, validate user identifiers, rate-limit requests and audit access to sensitive information. Never return password hashes, access tokens, reset tokens, recovery secrets or unnecessary personal data. This page intentionally does not perform role changes, account suspension or account deletion.
