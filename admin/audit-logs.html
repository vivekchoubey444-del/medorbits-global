Audit integrity requirements

The user interface does not create an audit trail by itself. Implement the following controls in the backend and infrastructure.

  • Record the actor, action, resource, UTC timestamp, outcome and request ID on the server.
  • Restrict access through server-side authorization and least-privilege roles.
  • Protect stored logs from unauthorized modification and deletion.
  • Redact passwords, tokens, secrets and unnecessary personal information.
  • Define retention, access, export and incident-response policies.
  • Use pagination and bounded date ranges for large audit datasets.
