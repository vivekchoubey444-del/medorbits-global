Password security checklist

Good practices for protecting your account.

  • Use a unique password Avoid reusing credentials from other websites or applications.
  • Prefer longer passphrases Long, unpredictable passwords are generally harder to guess.
  • Avoid personal information Do not use easily discovered details or common password patterns.
  • Use a reputable password manager Store unique passwords without having to remember each one.

Important security note

Password changes must be processed by the authenticated server over HTTPS. The server must verify the current password, enforce its password policy, store the replacement using an appropriate password hash, and protect the endpoint against unauthorized requests and abuse. The strength indicator on this page is guidance only and does not replace server-side validation. If you suspect unauthorized access, follow your application's account-recovery process.
