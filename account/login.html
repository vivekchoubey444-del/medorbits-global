Account security

Authentication must be enforced by the server, not by this page. The backend should verify credentials against a securely hashed password, use rate limiting and generic authentication errors, issue secure session cookies, and validate session state on protected routes. If persistent sign-in is supported, implement it using server-managed, revocable sessions or refresh tokens. Do not store passwords, session secrets or authentication tokens in localStorage. Protect state-changing requests against CSRF where applicable.
