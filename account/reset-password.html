How password reset works

Follow these steps to recover access to your account.

  • Use your reset link Open the link from the password-reset message you requested.
  • Choose a strong password Use a long, unique password that is difficult to guess.
  • Wait for server confirmation The reset is complete only after the server accepts the token and password.

Security reminders

Protect your account before and after resetting your password.

  • Keep your token private Anyone who obtains a valid reset token may be able to attempt account recovery.
  • Use the official website Check the address bar before entering any credentials.
  • Request another link if necessary Expired or already-used reset links should not be reused.
