Privacy and messaging security

The inbox must be protected by server-side authentication and conversation-level authorization. A user must only be able to read or reply to conversations they are authorized to access. Validate all message input on the server, apply rate limits, prevent cross-site scripting, protect state-changing requests against CSRF where applicable, and avoid exposing private message content in application logs. Never treat client-side filters or hidden elements as access controls.
