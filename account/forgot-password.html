What happens next?

Follow these steps to recover your account.

  • 1. Submit your registered email Use the email address associated with your MedOrbits account.
  • 2. Check your inbox Look for the reset email, including your spam or junk folder.
  • 3. Use the secure reset link Open the link promptly. Reset tokens should expire and be usable only once.
  • 4. Sign in with your new password Return to the sign-in page after the server confirms your password has changed.

Need more help?

If you cannot access your registered email address, contact support using the official MedOrbits contact page.

Important security note

This page must be connected to a secure backend. The server should generate cryptographically random, single-use reset tokens, store only a secure hash of each token, apply a short expiry, rate-limit requests, and send reset links only through a verified recovery channel. Responses should not disclose whether an email address belongs to an account. The server must validate the token and new password, securely update the password hash, invalidate the token, and handle relevant session revocation. Never put passwords or reset tokens in application logs.
