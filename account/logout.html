Before you leave

Protect your personal information and account access.

  • Use sign out on shared devices Always end your session on a public computer or a device used by someone else.
  • Close sensitive documents Make sure you have finished downloading or reviewing any private documents.
  • Keep your password private Do not save your password on an untrusted device or share it with another person.
  • Secure your account if needed If you suspect unauthorized access, change your password and contact support.

Security implementation note

This page must call a real server-side logout endpoint. The server must invalidate the active session and revoke or rotate applicable authentication credentials. If cookie-based authentication is used, clear the session cookie using the same path, domain and security attributes used when setting it. Protect state-changing requests against CSRF where applicable. Do not treat a frontend redirect, button click or cleared browser display as proof that the session has been invalidated.
