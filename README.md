# MedOrbits

**Education · Admissions · Careers · Recruitment**

This repository scaffold organizes the static website, shared frontend assets, structured data, API examples, Python utilities, SQL resources, tests and deployment documentation.

## Key paths
- `index.html` — root entry point
- `assets/css/` and `assets/js/` — shared frontend
- `assets/data/` — structured public reference data
- `education/` — courses, admissions, medical colleges and study abroad
- `career/` — jobs, recruitment and application preparation
- `api/`, `database/`, `migrations/` — backend and data resources
- `tests/`, `docs/`, `.github/workflows/` — quality and project operations

## Important
Most generated pages and modules are starter templates, not finished production features. Verify official institution names, recognition, fees, seats, deadlines, policies and all links before publication. Admin, account, payment, document-upload and API workflows require real server-side implementation and security controls.

Integrate selectively with the existing repository. Preserve existing routes and migration history; do not overwrite production files with this scaffold.
