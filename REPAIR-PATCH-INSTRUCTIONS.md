# Applying the MedOrbits repair patch

1. Make a backup or create a Git branch.
2. Extract this ZIP into the repository root, preserving folders.
3. Do not copy `.env`; it is intentionally excluded.
4. Review `git diff` before committing.
5. Run `npm run check:strict` after installing the project's declared development dependencies.

This patch archive contains changed files only, not a complete repository.
