/* ==========================================================================
   06. ACCESSIBILITY & INCLUSIVE DESIGN
   ========================================================================== */

/*
Accessibility Objectives:
  - Use semantic HTML and meaningful page titles.
  - Provide descriptive alternative text for informative images.
  - Use empty alternative text for purely decorative images.
  - Maintain sufficient text and interface contrast.
  - Support keyboard navigation and visible focus indicators.
  - Associate form fields with clear labels and instructions.
  - Provide understandable validation messages and error feedback.
  - Avoid relying on color alone to communicate meaning.
  - Respect reduced-motion preferences for animated interfaces.
  - Ensure responsive layouts and usable touch targets.

Standard:
  Design and test interfaces for accessibility throughout development,
  rather than treating accessibility as a final visual adjustment.
*/


/* ==========================================================================
   07. CONTENT QUALITY & DATA ACCURACY
   ========================================================================== */

/*
Content Standards:
  - Review public information before publication.
  - Use clear language, descriptive headings and consistent terminology.
  - Identify the source and relevant date of time-sensitive information.
  - Correct outdated, incomplete or misleading information promptly.
  - Distinguish verified facts from estimates, guidance and opinions.

Time-Sensitive Information:
  - Admission criteria and eligibility
  - Application procedures and deadlines
  - Tuition fees and other education-related costs
  - Scholarships and financial assistance
  - Examination schedules and official notifications
  - Job descriptions, eligibility criteria and employment terms

User Guidance:
  Users should verify final eligibility criteria, requirements, fees,
  deadlines and official decisions with the relevant institution,
  employer or authorized authority.

Important:
  MedOrbits content must not imply official affiliation, guaranteed
  admission, guaranteed employment or guaranteed scholarship approval
  unless such claims are accurate, authorized and appropriately supported.
*/


/* ==========================================================================
   08. PRIVACY, SECURITY & DATA PROTECTION
   ========================================================================== */

/*
Privacy Principles:
  - Collect only information necessary for a defined purpose.
  - Explain relevant data collection and usage practices.
  - Restrict access to confidential information.
  - Handle personal information according to applicable requirements.
  - Apply appropriate retention and deletion practices.

Security Requirements:
  - Use server-side authentication and authorization for protected data.
  - Enforce resource-level permissions on every relevant request.
  - Validate and sanitize untrusted input as appropriate.
  - Protect uploaded documents and confidential application records.
  - Store credentials and access tokens in appropriate secret storage.
  - Never expose secrets in frontend code, public JSON, logs or repositories.
  - Use secure transport and appropriate session protections.
  - Apply rate limits and abuse protections to sensitive endpoints.
  - Record security-relevant events without unnecessarily logging personal data.
  - Review dependencies, configuration and access controls regularly.

Data Exposure Rule:
  Public website assets must not contain credentials, private documents,
  authentication tokens, confidential user information or restricted records.

Implementation Note:
  Security controls must be enforced by the server and verified against
  the actual application architecture and deployment configuration.
*/


/* ==========================================================================
   09. SEARCH ENGINE OPTIMIZATION & DISCOVERABILITY
   ========================================================================== */

/*
SEO Standards:
  - Use descriptive page titles and meta descriptions.
  - Maintain a logical heading hierarchy.
  - Use meaningful URLs and descriptive internal links.
  - Provide appropriate canonical URLs where needed.
  - Maintain valid sitemap and robots directives.
  - Use structured data only when accurate and applicable.
  - Optimize image sizes and page performance.
  - Avoid duplicate, misleading or automatically generated low-value content.
  - Keep public information accessible to users and search engines where intended.

Search Experience:
  - Provide clear search controls and understandable results.
  - Show useful empty states when no matching information is available.
  - Distinguish unavailable sources from genuinely empty results.
  - Identify external sources where external information is displayed.
  - Never expose private records through public search functionality.
*/
