# Scope
# This policy applies to MedOrbits-owned websites, web applications,
# APIs, and services that are explicitly operated by MedOrbits.
# Third-party services are excluded unless explicitly authorized.

# Reporting Guidance
# Please include a clear description of the issue, affected URL or
# endpoint, potential impact, reproduction steps, and supporting
# evidence such as sanitized logs or screenshots.
# Include proof-of-concept code only when necessary and safe.
# Do not include passwords, access tokens, personal data, or other
# sensitive information in a report unless specifically requested
# through an approved secure channel.

# Responsible Disclosure
# Please make a good-faith effort to avoid privacy violations,
# service disruption, data modification, and unauthorized access.
# Do not conduct denial-of-service testing, social engineering,
# phishing, physical attacks, or tests against third-party systems.
# Do not access, alter, download, or retain data belonging to others.
# Stop testing and report the issue promptly if sensitive data is
# encountered or a system's security or availability may be affected.

# Safe Harbor
# MedOrbits welcomes good-faith security research conducted within
# the scope and guidelines of its published security policy.
# No authorization or legal protection beyond applicable law is
# implied by this security.txt file. Researchers should review the
# published policy before conducting any testing.

# Response Expectations
# MedOrbits aims to acknowledge valid reports within 5 business days
# and provide an initial assessment within 10 business days.
# Investigation and remediation timelines depend on severity,
# reproducibility, complexity, and operational risk.
# These are target timelines, not a guarantee of resolution.

# Data Handling
# Please minimize collection and retention of evidence.
# Redact personal information, credentials, session cookies,
# API keys, and other secrets before submitting a report.
# Use the contact channel above to request a safer reporting method
# if your evidence contains confidential or sensitive material.

# Disclosure
# Please allow MedOrbits a reasonable opportunity to investigate
# and address a reported vulnerability before public disclosure.
# Coordinate publication timing with MedOrbits where practical.
# Do not disclose personal data or confidential information.
