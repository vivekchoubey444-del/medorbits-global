Website:          https://medorbits.in

Protocol:         Robots Exclusion Protocol (REP)

Primary purpose:  Search engine crawling guidance

Sitemap:          https://medorbits.in/sitemap.xml

=====================================================================

POLICY OBJECTIVES

----------------------------------------------

1. Keep public education, admissions, career and information pages

accessible to search engine crawlers.

2. Discourage crawling of account-specific and operational routes.

3. Preserve access to public CSS, JavaScript, fonts and images.

4. Reduce crawling of internal search and selected parameter URLs.

5. Keep crawler-specific rules consistent with the default policy.

6. Publish only rules that correspond to the deployed URL structure.

SECURITY NOTICE

----------------------------------------------

This file is public and is not an access-control mechanism.

Enforce authentication, authorization and private-file protection

on the server. Do not expose secrets, personal records or private

documents through publicly accessible URLs.

09. INTERNAL SEARCH AND URL PARAMETER CONTROL

=====================================================================

These patterns are intended for crawl management, not security.

Verify them against actual production URLs before deployment.

Search-engine support for wildcard and query-string matching varies.

Do not block parameters that produce important, unique public content.

Prefer canonical tags for duplicate public URLs where appropriate.

=====================================================================

Internal search results

Disallow: /search?
Disallow: /search/

Sorting and ordering variants

Disallow: /?sort=
Disallow: /&sort=
Disallow: /?order=
Disallow: /&order=

Session and authentication-related query parameters

Disallow: /?session=
Disallow: /&session=
Disallow: /?sessionid=
Disallow: /&sessionid=
Disallow: /?token=
Disallow: /&token=
Disallow: /?access_token=
Disallow: /&access_token=
Disallow: /?auth=
Disallow: /&auth=
Disallow: /?password=
Disallow: /&password=
Disallow: /?verification=
Disallow: /&verification=
Disallow: /*?reset_token=
Disallow: /&*reset_token=

17. AI AND OTHER AUTOMATED CRAWLERS

=====================================================================

No blanket AI-crawler restriction is applied by this policy.

If a specific AI crawler policy is required, identify the crawler’s

documented user-agent token and define a dedicated group.

Separate policies may be required for search indexing, model training,

user-triggered retrieval and other automated access purposes.

Robots directives are voluntary crawler guidance, not a substitute

for authentication, authorization, rate limiting or access controls.
