# MedOrbits — Study in India section

This package expands the supplied `index.html` reference into a small, linked section for `/education/study-in-india/`.

## Contents

- `index.html` — supplied design reference, retained and given corrected page metadata plus an admission-guide CTA.
- `admissions.html` — admission routes and application workflow.
- `courses.html` — academic pathways and comparison criteria.
- `institutions.html` — recognition and institution due diligence.
- `fees-and-costs.html` — budget planning and fee verification.
- `scholarships.html` — funding discovery and fraud-aware preparation.
- `application-checklist.html` — document preparation checklist.
- `states-and-destinations.html` — destination comparison.
- `international-students.html` — international applicant planning.
- `official-resources.html` — official education links.
- `faq.html` — frequently asked questions.
- `assets/css/study-in-india.css` — shared responsive dark sapphire/champagne design system.
- `assets/js/study-in-india.js` — mobile navigation, current year, and optional client-side list filtering.
- `assets/data/*.json` — editable starter datasets for pathways, official links, and application checklist.

## Deployment

Copy the `study-in-india/` directory into the repository at `education/study-in-india/`. The shared CSS/JS links are absolute from the domain root and are expected at:

- `/education/study-in-india/assets/css/study-in-india.css`
- `/education/study-in-india/assets/js/study-in-india.js`

The supplied reference `index.html` continues to use its original inline design system and site-wide asset paths. The new sibling pages share the stylesheet above.

## Important

The JSON files are starter content, not a live or automatically refreshed database. Confirm all regulatory, admission, fee, counselling, scholarship, and visa details from current official notices. Official links are supplied as starting points and should be periodically checked.
