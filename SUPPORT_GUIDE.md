# MedOrbits Support Guide

Use only officially published and verified support channels. Do not publish unverified contact details, hours, response targets or escalation commitments.

Include the affected service, concise description, reproduction steps, approximate time, sanitized evidence and a reference number where appropriate. Never send passwords, one-time codes, API keys, session tokens, full payment-card details or unnecessary sensitive documents.

Report suspected vulnerabilities through a verified private process documented in `SECURITY.md`, not public issues or social media. Verify policy links before publication.
