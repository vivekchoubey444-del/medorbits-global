=============================================================================

MEDORBITS -- DEVELOPMENT & TESTING DEPENDENCIES

=============================================================================

File:          requirements-dev.txt

Project:       MedOrbits

Website:       https://medorbits.in

Purpose:       Local development, automated testing, linting and code quality

INSTALLATION

python -m pip install -r requirements-dev.txt

RUN TESTS

python -m pytest

RUN LINTING

python -m ruff check .

CHECK FORMATTING

python -m ruff format –check .

AUTO-FORMAT CODE

python -m ruff format .

SECURITY NOTES

1. Install dependencies inside an isolated virtual environment.

2. Review dependency updates before accepting them.

3. Pin exact versions in a generated lock file for reproducible CI builds.

4. Review transitive dependencies and security advisories regularly.

5. Keep development-only packages out of the production installation.

COMPATIBILITY

Target Python version: 3.10+

Verify package compatibility against the Python version used in CI.

VERSION POLICY

The ranges below define supported major-version boundaries; they do not

provide fully reproducible installations. Use a reviewed lock file when

deterministic builds are required.

MAINTENANCE REQUIREMENTS

=============================================================================

- Add only dependencies required by the development and testing workflow.

- Prefer actively maintained packages with compatible Python support.

- Review changelogs and security advisories before upgrading dependencies.

- Do not store credentials, API keys or private repository tokens in this file.

- Do not treat a successful installation as proof that the application is secure.

- Keep production dependencies in the appropriate production requirements file.

- Validate this file in CI using the same supported Python version as the project.
