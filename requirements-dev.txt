QUICK START

=============================================================================

1. Create a virtual environment:

python -m venv .venv

2. Activate the environment:

Windows PowerShell:

..venv\Scripts\Activate.ps1

Windows Command Prompt:

.venv\Scripts\activate.bat

Linux / macOS:

source .venv/bin/activate

3. Install development dependencies:

python -m pip install -r requirements-dev.txt

=============================================================================

TESTING, LINTING & FORMATTING

=============================================================================

Run automated tests:

python -m pytest

Run Python linting:

python -m ruff check .

Check formatting without modifying files:

python -m ruff format –check .

Automatically format Python files:

python -m ruff format .

Apply supported automatic lint fixes:

python -m ruff check –fix .

INSTALLATION & SECURITY POLICY

=============================================================================

1. Install development packages inside an isolated virtual environment.

2. Review dependency releases, changelogs and security advisories before

upgrading packages.

3. Generate and maintain a reviewed dependency lock file when deterministic

CI and local installations are required.

4. Review transitive dependencies and vulnerability reports regularly.

5. Keep development-only dependencies separate from production dependencies.

6. Do not store passwords, API keys, access tokens or private credentials

in this file.

7. A successful installation or test run does not prove that the application

is secure or production-ready.

8. Run CI checks against the Python version supported by the project.

9. Configure pytest, Ruff and coverage settings centrally where appropriate,

using pyproject.toml or the project’s established configuration.

10. Keep optional packages commented out until required by actual tests

or engineering workflows.

=============================================================================

VERSION & COMPATIBILITY POLICY

=============================================================================

The version ranges above define supported release boundaries; they do not

guarantee fully reproducible installations.

For reproducible CI builds:

- Resolve and review exact dependency versions.

- Maintain an appropriate lock or fully pinned requirements file.

- Validate installations against the supported Python version.

- Review dependency changes before merging.

Target Python version: 3.10+
